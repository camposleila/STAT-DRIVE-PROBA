# 🚗 STAT-DRIVE: Análisis y Visualización de Movilidad Estudiantil

Este repositorio contiene la estructura de la base de datos relacional y los recursos de visualización para el proyecto **STAT-DRIVE**, orientado al análisis de la eficiencia de transporte, tiempos de desplazamiento y caracterización de incidencias en trayectos universitarios.

## 📌 Características Principales
* **Base de Datos Relacional (`StatDriveDB`):** Gestión de tablas normalizadas para `estudiantes`, `trayectos`, `incidencias` y `RecargasCombustible`.
* **Indicadores Clave (KPIs):** Definición e implementación de la **Velocidad Ponderada** ($\frac{\text{Distancia Total}}{\text{Tiempo Total}}$) como métrica estandarizada de rendimiento.
* **Dashboard Interactivo:** Reporte dinámico en Power BI con análisis comparativo multi-estudiante, curvas de tendencia temporal y líneas de referencia analíticas.

## 🛠️ Tecnologías Utilizadas
* **Database Management:** SQL Server Management Studio (SSMS)
* **Visualización & BI:** Power BI Desktop
* **Exportación & Modelado:** CSV / Excel Data Pipeline
